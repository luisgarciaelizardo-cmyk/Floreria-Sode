# Florería Sode

Sitio web de **Florería Sode** — Sodelva Martínez, diseñadora floral.

Página estática (HTML, CSS y JavaScript, sin dependencias). Para verla, abre `index.html` en el navegador
o publícala con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

- `index.html` — estructura de la página
- `styles.css` — estilos
- `script.js` — catálogo (productos y precios), filtros y visor de imágenes
- `assets/img/catalogo/` — fotos extraídas del catálogo 2026
- `assets/catalogo-sode-2026.pdf` — catálogo original descargable

Para cambiar precios o agregar productos, edita la lista `productos` en `script.js`.
